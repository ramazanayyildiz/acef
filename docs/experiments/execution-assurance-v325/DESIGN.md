actors, `gpt-5.6-sol/high` routing, one Developer session per story, focused story verification, one broad epic suite,
hash-bound review capsules, and every fail-closed circuit breaker.

Its repairs are limited to the measured V3.24 closeout failures: typed-state Current Context synchronization, exact
supervisor-owned Epic Judge registration/terminal commands, correct two-layer story-close durability, and treating an
identical repeated capsule display as measured read waste rather than corrupted evidence. No safety role is merged.

The tool-call ceiling is recalibrated from the measured 286 calls to 320. All other time, token, cycle, actor, retry,
and repair limits remain unchanged. The run is sleep-inhibited, capped at 75 active minutes, fail-closed, and may run
exactly once.
