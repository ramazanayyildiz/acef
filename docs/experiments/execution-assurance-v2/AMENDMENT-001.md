# Preregistration Amendment 001

Recorded after Stage 0 and before any stochastic pilot attempt.

The attempt order is changed so the first run is a Repo Native drift sentinel, followed immediately by the paired
Full + Guarded motivating case. The six noise-floor Fix runs follow that pair. No task, treatment, time cap, oracle,
metric, or stop rule changed.

Reason: the independent Fable review identified the motivating Full + Guarded pair as the highest evidence-per-hour
test and recommended running it immediately after deterministic traps. Starting with the Native sentinel still gives
the campaign an environment/model drift reference. The amendment was made before seeing any pilot outcome.
